# 부산 무더위·한파 쉼터 3D 지도: 기획서 (3단계, 개정)

> `AI-워크플로우.md` 3단계의 결과물이에요.
> 2026-11-26 개정: 주제를 **팝업스토어 → 무더위·한파 쉼터**로 바꿨어요.
> 바꾼 이유: 팝업은 공식 데이터가 없고 금방 끝나요. 쉼터는 부산시 공식 데이터가 있고, 고령화라는 지역 문제와 바로 연결돼요.

## 한 줄 정의

폭염이나 한파 때 **어르신이 가장 가까운 쉼터를 바로 찾을 수 있도록**, 부산의 무더위·한파 쉼터 건물을 2D 지도 위에 **3D 입체로 세워 보여 주고**, 길찾기와 전화 걸기까지 연결하는 모바일 웹앱.

## 왜 이 주제인가 (심사 때 설명할 문제)

- 부산은 광역시 중 가장 먼저 **초고령사회**(65세 이상 20% 이상)에 들어섰어요.
- 폭염과 한파에 가장 위험한 사람은 혼자 사는 어르신이에요.
- 쉼터는 1,789곳(여름), 1,126곳(겨울)이나 있어요. 그런데 **"어디 있는지, 어떤 건물인지" 알기 어려워요.** 경로당은 주택가 골목 안에 있어서 주소만으로는 찾기 힘들어요.
- 우리 앱은 쉼터 건물을 **3D로 눈에 띄게** 세워서 "저 건물이구나"를 바로 알 수 있게 해요.

**데이터에 없는 것 (한계)**
- **운영 시간, 수용 인원, 전화번호가 없어요.** 공식 데이터에도 "냉방설비, 수용 인원 등은 포함되지 않음"이라고 적혀 있어요.
  - 보완 1: 행정안전부의 무더위쉼터 오픈 API에는 이용 가능 인원과 냉방기 현황이 있어요. 회원가입하고 키를 발급받아야 해요. SHOULD로 둬요.
  - 보완 2: 전화번호는 시연 지역의 쉼터만 직접 조사해서 넣어요.
- **쉼터가 모두 건물은 아니에요.** 공원, 정자, 파출소처럼 건물이 아니거나 작은 곳도 섞여 있어요.
- 데이터 등록일은 2025-11이에요. 실제 운영 여부는 다를 수 있어서, 앱에 "방문 전 전화 확인" 안내를 넣어요.

## 기능

| 구분 | 기능 |
|---|---|
| MUST | 2D 지도 위에 **쉼터 건물만 3D로** 표시 |
| MUST | **여름(무더위) / 겨울(한파) 전환**. 오늘 날짜를 보고 기본값을 자동으로 정해요 |
| MUST | 쉼터를 누르면 청사진 스타일 정보 패널: 이름, 주소, 종류(경로당/주민센터/도서관 등), 전화(있으면) |
| MUST | 길찾기: 청사진 스타일 "출발 전 확인" 시트 → 카카오맵/네이버지도로 넘기기 |
| MUST | 내 위치에서 **가장 가까운 쉼터 3곳** 바로 보기 |
| SHOULD | 버튼과 글자를 크고 둥글고 확실하게 (어르신 사용 기준) |
| SHOULD | 행정안전부 API로 수용 인원과 냉방기 정보 보강 |
| COULD | 오늘 기온이나 특보 표시 (기상청 API) |
| COULD | 자녀가 부모님 집 주소를 넣어 두고 "부모님 집 근처 쉼터"를 보는 모드 |

## 3D를 어떻게 보여 줄까 (이전 결정에서 바뀌는 부분)

이전 결정은 "로드뷰 사진에서 실제 건물 색을 뽑는다"였어요. 쉼터가 **약 2,900곳**이라 사진으로 하나씩 색을 뽑는 건 불가능해요. 그래서 이렇게 바꾸려고 해요.

1. **건물 모양: 지도에 있는 실제 건물 윤곽을 써요.**
   - 무료 지도 데이터(OpenStreetMap)에는 건물 바닥 모양과 높이가 들어 있는 경우가 많아요.
   - 쉼터 좌표에 있는 건물을 찾아서 **그 건물만 입체로** 세워요. 다른 건물은 납작하게 둬요.
   - 건물 데이터가 없는 곳은 좌표를 중심으로 작은 사각 건물을 세워요.
   - ⚠️ 부산 골목의 경로당까지 건물 데이터가 있는지는 **6단계 목업 전에 실제로 띄워서 확인**해야 해요.
2. **색: 계절 테마색을 써요.**
   - 여름: 주황·빨강 계열 (시원한 곳이라는 표시로 건물 꼭대기에 하늘색 띠)
   - 겨울: 하늘·남색 계열 (따뜻한 곳이라는 표시로 주황 띠)
   - 선택한 쉼터는 청사진 하늘색 선으로 빛나게 해요.
   - 시연할 동네의 쉼터 5~10곳만 **실제 건물 색**으로 꾸며서 "실제처럼 보인다"는 인상을 줘요. 이전에 정한 사진 색 추출 방식을 여기에만 써요.
3. **건물이 아닌 쉼터**(공원, 정자): 3D 건물 대신 **입체 정자(지붕) 모양 아이콘**으로 보여 줘요.
4. **층별 정보:** 쉼터 데이터에는 층 정보가 없어요. 건물 겉면만 그리고, 층별 이벤트 기능은 빼요. 이전 결정 그대로예요.

## 기술 스택

| 역할 | 선택 | 바뀐 점 |
|---|---|---|
| 화면 | React + Vite + TypeScript + Tailwind | 그대로 |
| 지도 | MapLibre GL JS + OpenFreeMap | 그대로 |
| 쉼터 데이터 | **CSV를 JSON 파일로 바꿔서 앱에 같이 넣음** | Supabase 대신 |
| DB | Supabase는 **나중에 필요할 때** (제보, 즐겨찾기 등) | MUST에서 뺌 |
| 배포 | Vercel | 그대로 |

**Supabase를 뺀 이유:** 쉼터 데이터는 약 2,900줄이고 거의 바뀌지 않아요. 앱 안에 파일로 넣으면 DB 서버가 필요 없어요. 시연 중에 DB 연결이 끊길 위험도 사라지고, 하루 개발 시간도 아낄 수 있어요.

## 화면 목록

1. **메인 지도**
   - 청사진 톤(남색 바탕, 하늘색 도로)의 2D 지도를 살짝 기울인 상태예요.
   - 쉼터만 3D로 솟아 있어요.
   - 상단: `여름 쉼터 / 겨울 쉼터` 전환
   - 하단 둥근 버튼 바: `내 위치`, `가까운 쉼터`, `길찾기`, `시점`
2. **쉼터 상세 (청사진 패널)**
   - 표제란 형식: 쉼터명 / 종류 / 주소 / 전화
   - 큰 버튼: `전화하기`, `길찾기`
   - 안내 문구: "방문 전에 운영 여부를 전화로 확인하세요"
3. **가까운 쉼터 목록**: 거리순 3곳, 큰 글씨
4. **빈 상태 / 로딩 / 에러**
   - 위치 권한 거부: "부산 시청 기준으로 보여 드릴게요"
   - 부산 밖: "부산 쉼터만 안내해요"

## 유지되는 이전 결정

- **청사진 디자인 방향**: 레퍼런스의 분위기와 구성만 참고해요.
- **길찾기 A안**: 우리 스타일의 확인 시트를 거쳐 카카오맵이나 네이버지도로 넘겨요. 넘어간 뒤 화면은 바꿀 수 없어요.
- **이 저장소의 커밋에는 공동 작성자(Co-Authored-By) 표시를 넣지 않아요.** Vercel 무료 요금제가 배포를 막아요.

## 결정 사항 (2026-11-26 확정)

1. **3D: 우리 색을 입히지 않아요.** 어르신이 지도를 보고 "이 건물이 그 쉼터가 맞구나"를 알아봐야 하기 때문이에요. 위 "3D를 어떻게 보여 줄까"의 계절 테마색 안은 **취소**해요.
   - 건물 모양은 지도 데이터의 **실제 건물 윤곽과 층수**를 써요.
   - 색은 지도 데이터에 **실제 건물 색**(`building:colour`)이 적혀 있으면 그 색을 쓰고, 없으면 칠하지 않은 **중립 콘크리트색**으로 둬요.
   - 선택한 쉼터는 건물을 칠하는 대신 **건물 위에 떠 있는 표시(핀)**로 알려 줘요.
   - "이 건물이 맞나?" 확인용으로 상세 패널에 **로드뷰 보기** 버튼을 둬요. 카카오맵 로드뷰가 열려 실제 사진을 볼 수 있어요.
   - 실제 건물 색이 없는 곳은 나중에 사진 색 추출 도구로 금정구 쉼터부터 채워요.
2. **사용자: 어르신 본인.** 글자는 크게(본문 18px 이상), 버튼은 크게, 한 화면에 할 일은 하나만 둬요.
3. **시연 지역: 부산 금정구.** 처음 화면은 금정구를 비추고, 실제 건물 3D는 금정구 쉼터부터 만들어요.
4. **이름 변경은 나중에** 해요.
5. **디자인: 청사진 스타일을 빼고 일반 지도 형식으로 해요.** 색이 들어간 일반 지도(OpenFreeMap liberty)에 흰 패널과 진한 글씨를 써요. 기본 지도의 입체 건물은 끄고 쉼터만 3D로 세워요.

## 현재 상태 (2026-11-26, 6단계 프로토타입)

- 쉼터 데이터: 1,906곳(여름 1,788 / 겨울 1,125, 좌표 오류 1곳 제외). 변환 도구는 `tools/build-shelters.mjs`예요.
- 실제 건물 윤곽(OpenStreetMap, 도구는 `tools/fetch-buildings.mjs`): **금정구 85곳 중 22곳만 찾았어요.** 실제 건물 색 정보는 **0곳**이에요. 한국의 작은 건물(경로당 등)은 OpenStreetMap에 거의 그려져 있지 않아요.
  - 못 찾은 63곳은 반투명 상자로 위치만 보여 줘요.
  - **개선안:** 국토교통부 건물 데이터(브이월드 등)에는 전국 건물 윤곽과 실제 층수가 있어요. API 키가 필요해서 사람이 계정을 만들어야 해요.
  - 실제 색은 사진(로드뷰) 기반 색 추출 도구로 금정구부터 채워야 해요.
- 동작 확인: 계절 전환, 쉼터 누르기 → 상세, 길찾기 확인 시트와 점선, 가까운 쉼터 3곳, 로드뷰·카카오맵·네이버지도 링크, 120 전화.
